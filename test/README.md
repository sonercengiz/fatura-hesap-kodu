# Testler

- `pnpm test` — birim testleri (Vitest): UBL XML ayrıştırma (jsdom), EDM düzeninde çıktı yazma, sıralama, öneri, hesap listesi, veritabanı geçişi (v3 → v6). Fikstürler `fixtures/` altında sentetik ve anonimdir.
- `test/*-e2e.mjs` — tarayıcı testleri (Playwright + Chrome; 48 betik). Kurulum: `pnpm install` yeter (Playwright bağımlılıklarda); makinede Chrome yoksa `pnpm exec playwright install chromium` ve betikleri `PW_CHANNEL=` ile koş. `pnpm dev --port 5179` açıkken: `node test/full-run-e2e.mjs`. Tam takım: `node test/tools/full-suite.mjs` (özet `<SCRATCH>/full/_summary.txt`). Yollar `test/paths.mjs`'te toplanır, ortam değişkeniyle değişir (macOS/Windows aynı): `SCRATCH` geçici çıktılar (varsayılan sistem geçici klasöründe `fhk-e2e`), `XML_DIR` gerçek e-Fatura XML'leri (varsayılan depo yanındaki `../xml fatura örnek`; depoya girmez), `DEMO_DIR` demo veri (varsayılan `<SCRATCH>/demo`), `OUT_DIR` rehber görselleri (varsayılan `public/guide`).
- `test/xslt-engines-e2e.mjs` — fatura görselini üç XSLT durumunda çizer (yerleşik / `XSLTProcessor` yok / var ama hata veriyor) ve hepsinin resmî şablonla, yerleşikle birebir aynı metinle çizildiğini denetler. CI'da (GitHub Pages iş akışı) üretim derlemesi üzerinde koşar: `BASE=<adres> PW_CHANNEL= DEMO_DIR=<demo> node test/xslt-engines-e2e.mjs`. Gerçek XML'lerle denemek için `DEMO_DIR` altında `xml/` klasörü yeter.
- `test/demo/make-demo.mjs <klasör>` — hayali firma seti (16 XML, 7 satıcı, kendi renkli şablonları; irsaliye ve bozuk dosya; ZIP; EDM listesi; kural dosyası; hesap kodları). Gerçek veri içermez.
- `test/guide-shots.mjs` — rehber görsellerini (`public/guide/*.png`) demo veriyle yeniden üretir: `node test/guide-shots.mjs` (`DEMO_DIR`, `OUT_DIR` isteğe bağlı) (uygulama 5179'da açıkken). Arayüz değişince ilgili bölümün görseli bu betikle yenilenir.
- `test/tools/` — görsel/denetim yardımcıları (uygulama 5179'da açıkken): `shots.mjs` önce/sonra kareleri (eski kodda `git stash push -- src` ile, sonra yeni kodda), `compose-ab.mjs` kareleri "Önce ↓ Sonra" olarak birleştirir (`ekran görüntüleri/<GG-AA>/`), `dark-check.mjs` az bakılan pencerelerin koyu tema kareleri, `full-suite.mjs` tam tarayıcı takımı.
